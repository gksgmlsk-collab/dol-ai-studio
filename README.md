# 돌 AI 창작연구소

초등학생이 생활 속 문제나 표현하고 싶은 장면을 발견하고, 작품을 시험한 뒤 근거를 남겨 고치는 로컬 창작 작업실입니다. 상단의 **친구 작품**에서 연습 예시와 담당 교사가 전시를 승인한 학급 작품을 볼 수 있습니다.

## 이 PC에서 열기

상위 폴더의 **돌 AI 창작연구소 시작.cmd**를 두 번 누릅니다. [돌 AI 창작연구소 열기](http://127.0.0.1:5174/)

실행기는 전용 모델 엔진과 웹 서버를 시작합니다. 이 PC에서 사용한 버전은 Node.js 26이며 내장 SQLite를 사용합니다.

```powershell
node start.mjs
```

웹 서버만 시작하려면 `node server.mjs --port 5174`를 실행합니다. 홈페이지의 **로컬 모델 상태**에서 대화·이미지·영상의 준비 상태와 설치 진척을 각각 확인할 수 있습니다. 상위 폴더의 `생각코드.html`은 개인 연습용 단일 파일입니다. 수업 계정과 모델 호출에는 실행 중인 서버 주소가 필요합니다.

## 학생과 교사의 시작 화면

표지에서 **학생 프로젝트 시작하기**를 누르면 다섯 가지 시작 방법이 보입니다. 아이디어부터 설계하기를 고르면 AI의 질문으로 생각을 정리합니다. 이미지·영상·3D·홈페이지 버튼을 누르면 선택한 공방을 엽니다. 수업에 로그인한 학생은 기존 프로젝트를 고르거나 첫 작품의 이름을 지어 시작합니다. [학생 메인](http://127.0.0.1:5174/#student)

교사는 표지의 **교사 학급 현황 보기**에서 로그인하고 담당 학급을 고릅니다. 학생별 접속 상태, 열린 공방·프로젝트와 최근 저장을 확인하고 저장한 작품 버전을 열 수 있습니다. [실시간 교실](http://127.0.0.1:5174/#teacher-live)

## 한 차시 진행 예

1. 담당 교사가 **교사 공간**에서 학급과 과제를 만들고 학생별 참여 정보를 발급합니다. 초기 교사 정보는 아래 저장 위치의 `first-teacher.txt`에 있습니다.
2. 학생은 **수업 참여**에서 로그인하고 개인 또는 모둠 프로젝트를 만듭니다. 목표·계획·대안과 선택 이유는 활동 중에도 바꿀 수 있습니다.
3. **생각 대화**에서 학생이 “학교 앞 길이 무서워요”라고 말하면 코치는 학생이 관찰한 점이나 시험해 보고 싶은 변화를 묻습니다. 학생이 정한 생각 카드를 이미지 공방으로 가져갑니다.
4. **영상·이미지**에서 자기 그림이나 생성 결과의 한 버전을 영상의 첫 장면으로 고릅니다. 움직임을 적어 로컬 AI 영상 생성을 요청합니다. **미술 감상·스토리보드**에서는 감상의 근거, 장면 순서·자막·길이·의도를 기록하고 선택한 장면을 공방으로 보냅니다.
5. **웹사이트**, **3D 설계**, **발명·로봇** 공방에서도 버전을 저장합니다. 각각 HTML, STL, 모형 장치의 동작 계획 파일을 내보냅니다. 구조의 강도, 실제 출력 결과, 물리 스위치 접촉은 실물 시험이 필요합니다.
6. **수업 프로젝트에 담기**로 작품 버전과 원하는 대화를 제출합니다. 교사는 버전이나 발화를 선택해 관찰 근거와 다음 질문을 기록합니다. 학생은 피드백 반영 여부를 적고 새 버전을 만듭니다. 전시할 자료를 골라 신청하면 교사가 확인한 뒤 공개합니다.

## 실제 수업 프로젝트

홈에서 **3D 발명품 프로젝트**를 열면 동봉된 원본 ‘교실 스위치 일체형 구동기’를 바로 조작합니다. 교사는 학급용 수정본이 있으면 HTML 또는 자료 폴더를 등록할 수 있습니다. **도시개발 프로젝트**에서는 미추홀 미래도시를 새 탭으로 열고, 돌아와 결과 파일이나 공유할 작품 주소, 관찰한 점을 담습니다. 도시 사이트에는 그곳에서 발급한 학급 코드로 참여합니다. 수업 프로젝트의 **제작 도구**에서 열면 해당 개인·모둠의 프로젝트에 기록이 연결됩니다.

**친구 작품**에서 전체 또는 작품 유형을 고릅니다. 여러 매체를 함께 전시한 작품은 해당 유형마다 나타납니다. 학급 공개는 담당 교사가 승인한 범위를 따릅니다.

교사 Google 로그인은 운영자가 웹 클라이언트 ID를 등록하고 기존 교사 계정에 연결하거나 교사를 초대하여 사용합니다. 이 PC의 로컬 Google 승인 원본은 `http://localhost:5174`입니다. [교사 Google 로그인 설정](./학급-운영.md)

## 저장과 운영

| 자료 | 기본 위치 |
|---|---|
| 수업 계정·모둠·작품 원본·버전·피드백·관찰 | `%LOCALAPPDATA%\DOL-AI-Studio\school\classroom.sqlite` |
| 첫 교사·운영자 접속 정보 | 같은 폴더의 `first-teacher.txt`, `first-operator.txt` |
| 로컬 엔진·모델과 생성 출력 | 프로젝트의 `.local/`과 `.local/jobs/` |
| 개인 연습 | 해당 브라우저의 로컬 저장소와 IndexedDB |
| 수업 도구 초안 | 계정과 탭에 묶인 브라우저 저장소. 다른 기기에서 이어갈 작품은 수업 프로젝트에 담습니다. |

계정 재발급, 교사 관찰, 연구용 JSON/CSV, 백업·복구는 [학급 운영 안내](./학급-운영.md)에 정리했습니다. 자유 서술에 들어간 학생 이름과 장소는 연구자가 확인합니다. 모델 설치 과정과 파일명은 [로컬 모델 안내](./로컬모델-연결.md)에서 확인할 수 있습니다.

## 학교 서버에서 열기

기본 실행은 이 PC에서만 접속할 수 있습니다. 교내 여러 기기로 운영할 때는 학교에서 신뢰하는 HTTPS 인증서와 교내 호스트 이름을 사용합니다. 아래 설정의 호스트·경로·포트를 학교 환경에 맞춥니다.

```powershell
$env:DOL_BIND_HOST = '0.0.0.0'
$env:DOL_CLASS_HOST = 'studio.school.example:8443'
$env:DOL_TLS_CERT = 'D:\school-certs\studio-chain.pem'
$env:DOL_TLS_KEY = 'D:\school-certs\studio-key.pem'
$env:DOL_SCHOOL_DIR = 'D:\school-data\dol-class'
node server.mjs --port 8443
```

학교 내부망에서 해당 주소에 접근할 수 있어야 합니다. 모델 서비스는 서버 자신의 루프백 주소에 둡니다. 학급망에서 AI를 호출하려면 학급 로그인이 필요합니다. 장비 없이도 스위치 모형 시뮬레이션과 버전 관리를 할 수 있습니다.

## Railway에 배포하기

Railway 서비스에 이 저장소를 연결하고 영구 볼륨을 `/data`에 마운트한 뒤 공개 도메인을 생성합니다. Dockerfile은 Node.js 26으로 서버를 실행합니다. 수업 계정과 작품은 `/data/school`에, 생성 작업은 `/data/jobs`에 보관합니다. 한 개의 레플리카를 사용합니다. [Railway 볼륨](https://docs.railway.com/volumes)

서버는 Railway가 주입한 `PORT`를 사용하고 `RAILWAY_PUBLIC_DOMAIN`을 HTTPS 주소로 인식합니다. 자체 도메인을 추가하면 `DOL_CLASS_HOST`에 그 호스트 이름을 설정합니다. 배포 상태는 `/healthz`에서 확인합니다. Google 교사 로그인에는 같은 HTTPS 주소를 승인된 JavaScript 원본으로 등록한 학교의 웹 클라이언트 ID가 필요합니다.

새 수업 서버는 독립된 교사·운영 계정을 발급합니다. 초기 접속 정보는 볼륨의 `school/first-teacher.txt` 및 `school/first-operator.txt`에 있습니다. 첫 실행 전에 Railway 서비스 변수 `DOL_TEACHER_SECRET`, `DOL_OPERATOR_SECRET`에 서로 다른 12자 이상의 값을 설정해도 됩니다. 교사는 로그인 후 학급을 만들고 학생에게 참여 코드를 안내합니다.

이 웹 컨테이너에서 생각 대화는 질문 카드로 이어갈 수 있습니다. AI 대화와 이미지·영상 생성에는 실행 중인 Ollama와 ComfyUI가 필요하며, 이 PC에 설치한 모델은 로컬 작업실에서 사용할 수 있습니다.

## 유지보수

```powershell
node server/school-test.mjs
node build-offline.mjs
```

홈의 이름과 문구는 `dist/site-config.mjs`, 교실과 엔진 연결은 `server/`, 공방 화면은 `dist/`에 있습니다. PNG와 WebM 등 실제 출력은 작업의 권한을 확인해 전달합니다. 웹 작품 미리보기는 스크립트와 외부 네트워크를 제한한 프레임에서 엽니다. 실제 센서·모터 연결은 장치별 입출력과 실물 시험 기록을 추가할 수 있는 확장 지점입니다.
